# 状态模型（体渲染 / 剖面 / 切面 / 地面）

这四个消费者共用同一份半精度数据纹理和 `localToTex` 采样，但各自持有一套样式。公共工具在 `web/src/state/fieldStyle.ts`：有限值域（`sanitizeRange`）、稀疏场默认低值透明、阈值换算成物理量。

## 体渲染

| 控件 | 含义 |
| --- | --- |
| 色带映射范围 | 变量的 `display_range`（与剖面显示同一变量时，跟剖面走）。只决定颜色，不裁掉体素。 |
| 透明阈值 | 色带映射范围上的归一化位置 0–1。面板上写成 `0.20 → 0.04 s⁻¹`：低于此值完全透明，之上逐渐显现。 |
| 数值窗口 | 硬裁剪：窗口外的体素不渲染。**不会**改色带映射。 |
| 切面 | 在 x/y/z 切割边界上画一层同变量的面。 |
| 切面低值透明 | 切面自己的低值渐隐，稀疏场（风切变、结冰指数等）默认打开，避免画出不透明黑墙。 |
| 切面跟随体渲染过滤 | 切面同时使用体渲染的数值窗口和透明阈值。 |

体渲染与剖面互斥：打开一个会关掉另一个。

## 剖面

变量、色带、值域、不透明度、低值透明是剖面自己的状态。切换变量时会重置为该变量的默认色带、`display_range` 和稀疏场默认的低值透明。手动值域如果某一端为空或非数字，回退到 `display_range`。

剖面**不会**套用体渲染的数值窗口。否则先看结冰指数（窗口 0–1）再切到北向风速（约 2–12 m/s），整面会被裁掉。

## 地面

「地面值域」是 2D 场自己的硬窗口，色带映射不变，白膜着色共用同一份遮罩。与体渲染、剖面的值域互不影响。

## 折线 / 框选：绘制状态与查看状态

| 状态 | 进入方式 | 地图左键 | 手柄 |
| --- | --- | --- | --- |
| 绘制 | 进入折线/框选且还没有几何；面板「编辑」「重画」；再点一次同一模式按钮 | 折线：加点；框选：拖拽画框 | 可拖 |
| 查看 | 折线：双击 / 回车 / 右键单击空白 /「完成」；框选：松开鼠标；Esc 取消 | 不再编辑几何，交给探针或相机 | 顶点、四角仍可拖 |

- 「编辑」：保留现有几何继续画（折线继续加点）。「重画」：清掉重画。「清除」：删掉几何，留在查看状态。
- Esc：放弃这次绘制，恢复到进入「编辑 / 重画」之前的几何；画到一半的框直接丢弃。
- 右键拖动是旋转相机，只有不移动的右键单击才算「完成」；右键点在顶点上是删点。
- 双击会落两次点，结束时去掉重复的末点；少于 2 点的折线会被清掉。

**地图点击仲裁**（`clickOwner()`）：先看是否点中手柄（剖面拖动条、高度手柄、折线顶点、框角），点中就拖手柄；否则按 绘制中的工具 > 探针（已打开）> 相机。绘制时打开探针会结束绘制并保留几何。

## 还没做成单一数据源的部分

体渲染和剖面仍是两份 reactive 状态，只在「同一变量」时由 `volumeStyleFor()` 对齐色带和值域。继续拆会动到面板绑定，这一轮先把规则收口、把冲突修掉。

## 时间轴（v6.11）

时间是独立的全局状态（`web/src/state/timeline.ts` 的 `timeline`），和上面的体渲染、剖面、地面样式以及绘制 / 查看状态都正交：切换体渲染 / 剖面、换变量、进入绘制状态都不改时间；拖时间轴、播放也不改任何样式或几何。

| 字段 | 含义 |
| --- | --- |
| `t` | 连续时间下标 0 … frames−1，整数就是原始时次（f000…f006） |
| `playing` | 播放中；`t += dt × rate / 4 s`（1× = 1 小时数据播 4 秒） |
| `rate` | 倍速 0.5× / 1× / 2× / 4× |
| `smooth` | 帧间平滑，默认开；关掉时按整点切换（显示 ⌊t⌋） |
| `loop` | 循环播放；末帧停 0.5 小时数据时长（1× 下 2 s）后回到 t=0，粒子不重置 |
| `ready[i]` | 第 i 帧已在滑动窗口内且编码字节已在 Worker 缓存（风场 + 当前打开的变量），刻度点亮 |
| `buffering` | 播放到下一帧时 GPU 槽位还没就绪，停在整点等待，播放头旁显示转圈 |
| `scrubbing` | 正在拖进度条；拖动会暂停播放，松手后保持暂停 |

规则：

- **控件**：播放 / 暂停、上一帧、下一帧、倍速、平滑开关、可点击 / 拖动的进度条（7 个刻度，点刻度跳到该整点）。上一帧 / 下一帧把 `t` 吸附到相邻整数并暂停。键盘：空格播放 / 暂停，← / → 步进；焦点在输入框里时不响应；Esc 仍归绘制状态。
- **时刻显示**：直接用文件里的字面时间（`2026-11-11 00:00` … `06:00`）。文件没有标时区，界面不加 UTC 或北京时间标签。
- **一张“当前时刻”纹理**：每个在用的 3D 量（风场 RGBA16F、水平风速、体渲染 / 剖面变量）有一个 `WebGL3DRenderTarget`，GPU 混合 pass 把 ⌊t⌋、⌊t⌋+1 两个槽位按权重写进去。粒子、体渲染、切面、水平切片、经纬剖面、折线墙、框选层叠都只采样这一张，所以同一时刻、互相一致；只有 `t` 变化时才混合，暂停时零开销。风场是保模长插值（方向取线性混合的矢量，模长取两帧模长的线性混合），水平风速 = 两帧模长的线性混合。
- **色带和数值范围跨时次固定**：色带只用 manifest 的 `display_range`；体渲染数值窗口滑块的边界用 7 帧并集的 `data_min/max`（水平风速用 `derived.speed.display_range`），播放时不跳。过滤（数值窗口、地面值域、透明阈值）都不改色带。当前帧有超出色带的值时，色例两端的三角箭头亮成琥珀色。
- **CPU 读数**：探针廓线、地面 2D 场（及白膜着色）、折线展开图按同样的混合规则读 ⌊t⌋、⌊t⌋+1 两帧的 Float32。播放或拖动时探针 10 Hz、地面和展开图 4 Hz 节流，停下后立即刷新到精确值。`atmos:probe` 消息带 `t` 和 `valid_time`。
- **几何不随时间变**：探针固定点、剖面位置、折线顶点、框选四角都是空间量，换时间不动；播放中也可以画折线、框选。
- **数据（滑动窗口）**：只请求当前打开的变量，窗口是 ⌊t⌋、⌊t⌋+1 和 ⌊t⌋+2（常量 `FETCH_WINDOW_AHEAD = 2`，两种格式共用）。打开时拉当前帧和后两帧；播放每进一小时只新增刚进入窗口的那一帧。多预取一帧，是为了在走到下一个整点之前就把下一区间要用的文件先请求下来，避免每个整点都停下来等下载。离开窗口的帧会释放 Worker 里的编码字节、主线程上的 Float32 / half，以及 GPU 槽位。拖动时间轴跳帧时，取消窗口外尚未完成的请求，优先拉新位置。下一帧没就绪时播放停在整点等待，不跳帧、不黑屏。循环到末帧时窗口是 `[末帧, 0, 1]`，回到起点前已经预取了 t000 和 t001。GPU 各留 3 个槽位，默认窗口正好用满（当前、下一、预取），换槽分批按层上传。
- **调试 API**：`__atmosApi.setTime(t) / play() / pause() / stepFrame(±1) / setPlayback({ rate, smooth, loop }) / hasFrame(t?) / timeline() / timeStats() / debugTimeTexel(name, ix, iy, k)`；`?t=3` 打开指定时刻，`?timeline=0` 隐藏时间轴，`?data=lowair_atmos` 打开单时次数据。
